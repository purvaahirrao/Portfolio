# Purva Ahirrao - Portfolio Website

A clean, minimal, and responsive personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Left Sidebar Navigation**: Fixed sidebar on desktop with active section highlighting
- **Mobile-Friendly**: Converts to top navigation on mobile devices
- **Smooth Scrolling**: Navigation links scroll smoothly to sections
- **Clean Architecture**: Simple, maintainable code structure
- **Light Theme**: Minimal design with proper spacing and readability

## Tech Stack

- **Frontend**: React 19.2.5 with TypeScript
- **Styling**: Tailwind CSS v4.2.4
- **Build Tool**: Vite 8.0.10
- **Icons**: Simple emoji icons for minimal design

## Local Development

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd myPortfolio/frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:5173
```

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
